# 청년부 청구함

리더들이 예산을 쓴 뒤 영수증과 함께 청구하고, 회계가 매주 금요일 마감 후 한 번에 입금하는 사이트입니다.

- 화면: `index.html` 한 파일 (GitHub Pages에 올림)
- 서버: `Code.gs` (구글 시트에 붙는 Apps Script, 무료)
- 교제비(반기 1회 항목)는 모임 당일 여러 가게에서 나눠 결제한 것을 한 청구로 낼 수 있습니다. 현금 결제는 청구할 수 없습니다.
- 저장: 구글 시트(청구 내역·예산·명단·규정), 구글 드라이브(영수증 사진), 회계 전용 스프레드시트(계좌번호)

`index.html`의 `API_URL`이 비어 있으면 가짜 데이터로 움직이는 시안 모드입니다. 주소를 넣으면 실제 시트와 연결됩니다.

---

## 설치 (처음 한 번, 약 20분)

모든 파일은 **시스템 관리자 계정(관리자 본인의 Gmail)** 으로 만드세요. 사이트에서 들어오는 청구는 이 계정 이름으로 시트·드라이브에 기록됩니다. 회계와 회장단은 7단계에서 편집자로 공유합니다.

### 1. 시트와 스크립트 만들기

1. 관리자 계정으로 구글 시트를 새로 만들고 이름을 `청년부 청구함`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 `Code.gs` 내용을 붙여넣은 뒤 저장합니다.
4. 왼쪽 **프로젝트 설정(톱니바퀴)** 에서 시간대를 `(GMT+09:00) 서울`로 바꿉니다.

### 2. 처음 설정 실행

1. Apps Script 위쪽 함수 선택에서 `setup`을 고르고 **실행**을 누릅니다.
2. 권한 요청이 뜨면 관리자 계정으로 승인합니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 청년부 청구함(으)로 이동**을 누릅니다. 직접 만든 스크립트라 뜨는 화면입니다.
3. 실행이 끝나면 시트에 탭 9개, 드라이브에 `청년부 청구함 영수증` 폴더, `청년부 청구함 계좌 (회계 전용)` 스프레드시트가 생깁니다.
4. 시트를 새로고침하면 위쪽에 **청구함 관리** 메뉴가 생깁니다.

### 3. 실제 내용 채우기

| 탭 | 할 일 |
| --- | --- |
| 설정 | `공동체암호`를 바꾸고, `회계메일`에 회계 2명 주소를 쉼표로 적기 |
| 소속 | 팀·셀·또래·임원단과 등록 인원 (예시 행은 지우고 새로) |
| 명단 | 청구할 사람 이름과 소속·직분 (소속은 드롭다운). 회색 칸은 건드리지 않기 |
| 예산항목 | 항목명, 대상 유형, 정액/인당, 금액, 반기 1회 여부 등 |
| 규정 · FAQ · 헷갈리는것 | 사이트에 보일 문구. `대상유형`에 `팀`처럼 적으면 그 유형에게만 보임 (여러 개는 `셀,또래,팀`) |

사람이나 소속이 빠질 때는 행을 지우지 말고 `사용`을 `N`으로 바꾸세요. 지난 청구 기록이 깨지지 않습니다.

### 4. 웹 앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택에서 **웹 앱**을 고르고 다음처럼 설정합니다.
   - 실행 사용자: **나** (관리자 계정)
   - 액세스 권한: **모든 사용자**
3. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
4. `index.html`을 열어 위쪽의 `const API_URL = '';` 따옴표 안에 그 주소를 붙여넣습니다.

### 5. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 무료 계정은 Pages를 쓰려면 공개 저장소여야 합니다. 저장소에는 화면 코드만 있고, 데이터는 공동체 암호와 PIN으로 막혀 있습니다.
2. `index.html`을 올립니다.
3. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장합니다.
4. 1~2분 뒤 나오는 주소(`https://아이디.github.io/저장소이름/`)를 리더 단톡방에 공지합니다.

### 6. 자동 메일 켜기

시트 메뉴 **청구함 관리 → 자동 메일 켜기**를 한 번 누릅니다.

- 매주 금요일 마감 시각 직후(설정의 `마감요일`, `마감시각` 기준, 15~45분 사이) 회계에게 이번 주 청구 요약 메일이 한 통 갑니다.
- 메일은 **이 메뉴를 누른 사람의 Gmail에서** 보내집니다. 관리자 계정이 아니라 회계 계정에서 보내고 싶으면 회계가 직접 이 메뉴를 누르면 됩니다. 두 사람이 각각 누르면 메일이 두 번 가니 한 명만 누르세요.
- 청구자에게는 메일을 보내지 않습니다. 보류되면 사이트의 ‘내 청구’ 탭에 숫자 배지와 안내가 뜹니다.

### 7. 공유 권한

시트만 공유하면 영수증 폴더와 계좌 파일은 따로 공유되지 않습니다. 세 파일을 각각 공유하세요.

| 파일 | 회계 2명 · 회장단 3명 |
| --- | --- |
| 청년부 청구함 (시트) | 편집자 |
| 계좌 (회계 전용) 스프레드시트 | 편집자 |
| 청년부 청구함 영수증 (폴더) | 편집자 |

- 정산 목록 만들기, 입금 완료 처리 같은 메뉴는 누른 사람 계정으로 실행됩니다. 처음 누를 때 권한 승인 화면이 한 번 뜨는 게 정상입니다.
- 관리자를 다른 사람에게 넘길 때: 세 파일의 소유권을 넘기고, 새 관리자가 4단계(웹 앱 배포)를 다시 한 뒤 `index.html`의 `API_URL`을 새 주소로 바꿔 올리면 됩니다.

## 회계 주간 업무 (휴대폰)

명단 탭의 `권한` 칸에 `회계`라고 적힌 사람은 사이트 하단에 **정산** 탭이 생깁니다. `열람`이라고 적으면 현황만 볼 수 있습니다(계좌번호는 안 보임).

1. 금요일 마감 직후 요약 메일을 받습니다. 설정 탭 `사이트주소`에 GitHub Pages 주소를 적어두면 메일에 정산 탭 링크가 들어갑니다.
2. 사이트 **정산 → 확인** 탭: 사진을 눌러 크게 보고 **확인** 또는 **보류**(사유 칩 선택)를 누릅니다.
3. **송금** 탭: 사람별 합계가 나옵니다. **계좌 복사 / 금액 복사** → 은행 앱에서 송금 → 돌아와서 **송금했어요 → 입금 완료**.
4. 실수로 입금 완료를 눌렀으면 **지난 내역**에서 그날 안에 **되돌리기**.

모든 처리는 청구내역 탭에 `처리자`, `처리시각`과 함께 기록되고, 입금 완료는 `정산` 탭에도 한 줄씩 남습니다. 시트 메뉴(정산 목록 만들기, 입금 완료 처리)는 PC에서 한꺼번에 처리하고 싶을 때만 쓰면 됩니다.

영수증 사진은 드라이브 `청년부 청구함 영수증 / 2026-11 / 미디어팀 /` 처럼 월별·소속별 폴더에 `20261112_미디어팀_팀사역비_24000원_장도현_영수증1_2611-0017.jpg` 형식으로 저장됩니다.

### 자주 하는 관리

- **보류 처리**: `보류사유`를 적고 `상태`를 `보류`로 바꾸면, 청구자가 사이트에 들어왔을 때 배지와 사유가 보입니다. 급한 건은 따로 연락해주세요.
- **PIN 초기화**: 명단 탭에서 그 사람의 줄을 선택하고 메뉴 **선택한 사람 PIN 초기화**. 5번 틀려 잠긴 사람도 이걸로 풀립니다.
- **명단 추가**: 명단 탭에 한 줄 추가하면 바로 입장할 수 있습니다.
- **반기 예산**: 상반기(12~5월), 하반기(6~11월)는 사용일 기준으로 자동 계산됩니다. 금액이 바뀌면 예산항목 탭의 `금액`만 고치면 됩니다.

## 코드를 고친 뒤

- `Code.gs`를 고쳤으면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 새 칸(`권한`, `처리자` 등)은 첫 요청 때 시트에 자동으로 추가됩니다. 이렇게 하면 웹 앱 URL이 바뀌지 않습니다. `새 배포`를 누르면 URL이 바뀌니 주의하세요.
- `index.html`을 고쳤으면 GitHub에 다시 올리면 1~2분 뒤 반영됩니다.

## 보안 메모

- 사이트에 들어오려면 공동체 암호, 본인 확인에는 이름 + PIN 4자리가 필요합니다. PIN은 시트에 암호화(해시)되어 저장되고, 5번 틀리면 잠깁니다.
- 사이트는 로그인한 사람의 소속 예산·규정·청구만 받아옵니다. 다른 사람의 청구나 계좌는 사이트로 볼 수 없습니다.
- 계좌번호는 회계 전용 파일에만 저장되고, 사이트에 다시 표시되지 않습니다. 청구자 휴대폰에는 본인이 선택한 경우에만 저장됩니다.
- 회계연도가 끝나고 감사를 마치면 계좌 파일의 계좌 열은 지우는 것을 권장합니다.
